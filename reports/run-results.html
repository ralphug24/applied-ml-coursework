How to read the records

Each full record includes task configuration, sample scope, seed, actual execution timestamp, environment versions and code checksum. Training occurred on a shared CPU environment with two threads per process; elapsed time is not a hardware benchmark.

Original Fall 2025 saved submission outputs are retained separately. Portable versions update paths and document changes to splitting, preprocessing and evaluation. Read the methodology guide before comparing results.
